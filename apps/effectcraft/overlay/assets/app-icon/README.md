# Fluxa app icon

The Fluxa icon was made for thaipro.store and replaces the upstream artwork, which belongs to its
authors. Files are rendered from one master picture:

- `fluxa-1024.png`, `fluxa-macos-512.png` and `fluxa.icns`: macOS, on Apple's icon grid.
- `fluxa.ico`: Windows, 16 to 256 px.
- `hicolor/<size>/apps/`: Linux icon theme.
- `*.svg`: the same picture wrapped in a vector container.
