# Pixelume app icon

The Pixelume icon was made for thaipro.store and replaces the upstream artwork, which belongs to its
authors. Files are rendered from one master picture:

- `pixelume-1024.png`, `pixelume-macos-512.png` and `pixelume.icns`: macOS, on Apple's icon grid.
- `pixelume.ico`: Windows, 16 to 256 px.
- `hicolor/<size>/apps/`: Linux icon theme.
- `*.svg`: the same picture wrapped in a vector container.
