# Clipora app icon

The Clipora icon was made for thaipro.store and replaces the upstream artwork, which belongs to its
authors. Files are rendered from one master picture:

- `clipora-1024.png`, `clipora-macos-512.png` and `clipora.icns`: macOS, on Apple's icon grid.
- `clipora.ico`: Windows, 16 to 256 px.
- `hicolor/<size>/apps/`: Linux icon theme.
- `*.svg`: the same picture wrapped in a vector container.
