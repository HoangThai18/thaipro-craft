# Focalo app icon

The Focalo icon was made for thaipro.store and replaces the upstream artwork, which belongs to its
authors. Files are rendered from one master picture:

- `focalo-1024.png`, `focalo-macos-512.png` and `focalo.icns`: macOS, on Apple's icon grid.
- `focalo.ico`: Windows, 16 to 256 px.
- `hicolor/<size>/apps/`: Linux icon theme.
- `*.svg`: the same picture wrapped in a vector container.
