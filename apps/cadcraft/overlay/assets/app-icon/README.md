# Drafta app icon

The Drafta icon was made for thaipro.store and replaces the upstream artwork, which belongs to its
authors. Files are rendered from one master picture:

- `drafta-1024.png`, `drafta-macos-512.png` and `drafta.icns`: macOS, on Apple's icon grid.
- `drafta.ico`: Windows, 16 to 256 px.
- `hicolor/<size>/apps/`: Linux icon theme.
- `*.svg`: the same picture wrapped in a vector container.
