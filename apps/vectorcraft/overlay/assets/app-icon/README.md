# Bezio app icon

The Bezio icon was made for thaipro.store and replaces the upstream artwork, which belongs to its
authors. Files are rendered from one master picture:

- `bezio-1024.png`, `bezio-macos-512.png` and `bezio.icns`: macOS, on Apple's icon grid.
- `bezio.ico`: Windows, 16 to 256 px.
- `hicolor/<size>/apps/`: Linux icon theme.
- `*.svg`: the same picture wrapped in a vector container.
