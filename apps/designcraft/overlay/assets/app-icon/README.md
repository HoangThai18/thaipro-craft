# Layouta app icon

The Layouta icon was made for thaipro.store and replaces the upstream artwork, which belongs to its
authors. Files are rendered from one master picture:

- `layouta-1024.png`, `layouta-macos-512.png` and `layouta.icns`: macOS, on Apple's icon grid.
- `layouta.ico`: Windows, 16 to 256 px.
- `hicolor/<size>/apps/`: Linux icon theme.
- `*.svg`: the same picture wrapped in a vector container.
