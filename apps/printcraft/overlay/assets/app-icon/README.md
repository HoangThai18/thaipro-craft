# Pagena app icon

The Pagena icon was made for thaipro.store and replaces the upstream artwork, which belongs to its
authors. Files are rendered from one master picture:

- `pagena-1024.png`, `pagena-macos-512.png` and `pagena.icns`: macOS, on Apple's icon grid.
- `pagena.ico`: Windows, 16 to 256 px.
- `hicolor/<size>/apps/`: Linux icon theme.
- `*.svg`: the same picture wrapped in a vector container.
