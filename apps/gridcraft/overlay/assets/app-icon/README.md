# Cellaro app icon

The Cellaro icon was made for thaipro.store and replaces the upstream artwork, which belongs to its
authors. Files are rendered from one master picture:

- `cellaro-1024.png`, `cellaro-macos-512.png` and `cellaro.icns`: macOS, on Apple's icon grid.
- `cellaro.ico`: Windows, 16 to 256 px.
- `hicolor/<size>/apps/`: Linux icon theme.
- `*.svg`: the same picture wrapped in a vector container.
