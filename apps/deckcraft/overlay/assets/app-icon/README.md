# Stagely app icon

The Stagely icon was made for thaipro.store and replaces the upstream artwork, which belongs to its
authors. Files are rendered from one master picture:

- `stagely-1024.png`, `stagely-macos-512.png` and `stagely.icns`: macOS, on Apple's icon grid.
- `stagely.ico`: Windows, 16 to 256 px.
- `hicolor/<size>/apps/`: Linux icon theme.
- `*.svg`: the same picture wrapped in a vector container.
