# Wavely app icon

The Wavely icon was made for thaipro.store and replaces the upstream artwork, which belongs to its
authors. Files are rendered from one master picture:

- `wavely-1024.png`, `wavely-macos-512.png` and `wavely.icns`: macOS, on Apple's icon grid.
- `wavely.ico`: Windows, 16 to 256 px.
- `hicolor/<size>/apps/`: Linux icon theme.
- `*.svg`: the same picture wrapped in a vector container.
