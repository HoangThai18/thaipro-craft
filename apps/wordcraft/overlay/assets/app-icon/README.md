# Inkora app icon

The Inkora icon was made for thaipro.store and replaces the upstream artwork, which belongs to its
authors. Files are rendered from one master picture:

- `inkora-1024.png`, `inkora-macos-512.png` and `inkora.icns`: macOS, on Apple's icon grid.
- `inkora.ico`: Windows, 16 to 256 px.
- `hicolor/<size>/apps/`: Linux icon theme.
- `*.svg`: the same picture wrapped in a vector container.
